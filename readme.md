# Text Stats

Analyze long strings of text to compute basic statistics.

## Learning Outcomes

1. Use `for` loops to iterate over characters
2. Implement counting logic using variables
3. Apply conditional logic within loops

## Usage

Run the program to see statistics for a sample text:

```
python3 textstats.py
```

## Testing

The program uses `doctest` for verification. Tests will run automatically when your program is run.

## Tasks

1. Implement `count_chars` to count all characters including whitespace
2. Implement `count_words` by identifying transitions from whitespace to non-whitespace
3. Implement `count_sentences` by counting terminal punctuation (., !, ?)
4. Implement `count_paras` by identifying double newlines
